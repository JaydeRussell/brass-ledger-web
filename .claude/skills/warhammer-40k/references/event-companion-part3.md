# Event Companion — Part 3 (pages 63-93)

This entire page range is a single section: the **Base Size Guide**, a
reference appendix listing the official base size (or "Hull"/"Unique"/
flying-base-size designation) for every unit in every faction's range.
It is organized as one alphabetical run of faction sub-sections (by
faction name), each headed by a large sidebar-style title, with a
two-column table (`UNIT` / `BASE SIZE`) beneath it. Some factions'
tables include an internal gray divider row for an "IMPERIAL ARMOUR"
(Forge World) or "DAEMONS" (allied Chaos Daemons units usable in that
codex) sub-group, listed after that faction's core units.

**This range starts mid-section.** Page 63 opens directly on "BLACK
TEMPLARS" with no section-opening header of its own — the Base Size
Guide clearly begins earlier in the document (alphabetically before
Black Templars: e.g. Adepta Sororitas, Adeptus Custodes, Adeptus
Mechanicus, Aeldari, Astra Militarum, and any other A-name factions
would precede it), so treat this file as a continuation of a Base Size
Guide section started in an earlier page range, not the start of it.
The range runs alphabetically through faction names and ends cleanly
at "WORLD EATERS" on page 93, the last page of the 93-page document —
there is no further section after it (no Legal/Credits page, no
back-cover text, nothing else was found in this range).

**No other content type appears in this range** — no Force Disposition
matrix, no primary-mission VP scoring, no terrain layouts, no secondary
mission cards, no doubles/teams-event rules, and no credits/legal text.
All of that content, if present in this document at all, lies outside
this assigned range.

## Special action term definitions

None found in this PDF's pages 63-93 — this entire range is exclusively
the Base Size Guide (unit-name-to-base-size tables, faction by faction).
None of the 9 terms, nor any mission-card text, secondary mission
cards, or glossary of any kind, appear anywhere in this range. Since
the "Primary Missions Print Sheets" PDF (see `primary-missions.md` in
this skill) is front-faces-only, the physical card backs are the only
place these terms' rule text is officially printed — this Event
Companion PDF simply doesn't carry it either.

**Update, resolved 2026-09-14**: found via a different route. Wahapedia
(a fan site) publishes a transcription of this same Chapter Approved
Mission Deck at `wahapedia.ru/wh40k11ed/the-rules/mission-deck-2026-27/`,
including the reverse-side "Objective Action" text for every mission —
cross-checked against this project's own front-card VP text first (mission
names, VP values and thresholds matched exactly), giving high confidence
it's the same 2026-27 card set, not a different season's revision. All 9
terms are now defined in `app/lib/missionActionGlossary.ts`'s
`SPECIAL_ACTION_DEFINITIONS`, wired into `missionMatchupPanel.tsx`'s
per-mission rules disclosure, and cited in `missionSources.ts`'s new
`wahapediaMissionDeck` entry. `MISSING_GLOSSARY_TERMS` has been removed
from `missionMatchups.ts` — it's no longer accurate to call this a gap.

All base sizes below are transcribed exactly as printed, including odd
formatting quirks in the source (e.g. inconsistent oval-base notation
order, "Armageddon" alternate-sculpt entries, and units named after
special characters).
